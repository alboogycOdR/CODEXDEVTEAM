## Phase 6 — Pilot

- [ ] Run a fresh real project end-to-end.
- [ ] Hand an existing DEVDEPARTMENT project to CODEXDEVTEAM and back.
- [ ] Verify no duplicate claims/reviews under lease contention.
- [ ] Measure first-pass rate, review sessions, gate rejection rate and model spend.
- [ ] Tag v0.1 only after both fresh and interoperability pilots pass.

## Deferred until evidence justifies them

- automatic safety-posture flips;
- unbounded autonomous model routing;
- memory facts without evidence;
- co-HEAD operation;
- vendor-specific features that cannot degrade cleanly on another runtime.
